題目敘述：把6個5-bit的輸入向量(a~f，共30-bit)串接起來，再拆分成4個8-bit的輸出向量(w,x,y,z，共32-bit)。串接方式是a,b,c,d,e,f依序接在一起，最後補上兩個bit的1，湊滿32-bit後由w到z依序切割輸出。
